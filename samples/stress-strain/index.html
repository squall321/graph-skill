LLM 프롬프트 품질 비교

같은 목표(Stress-Strain Curve) — 구체적 지시 vs 뭉뚱그린 지시

Case 1 — 구체적 전문 지시

Good

Canvas API · bezierCurveTo · Region fill · 접선 + Et · Responsive · Dark mode

실제 프롬프트
연성 재료(mild steel)의 공학적 응력-변형률 선도(Engineering Stress-Strain Curve)를 순수 HTML + Vanilla JS Canvas API로 구현해줘. 외부 라이브러리는 쓰지 마. [데이터] X축: 공학적 변형률 ε (0 ~ 0.30) Y축: 공학적 응력 σ (0 ~ 600 MPa) 주요 포인트: - Proportional Limit: ε=0.001, σ=200 MPa - Elastic Limit: ε=0.0012, σ=210 MPa - Upper Yield Point: ε=0.002, σ=250 MPa - Lower Yield Point: ε=0.003, σ=220 MPa - UTS: ε=0.20, σ=580 MPa - Fracture: ε=0.28, σ=420 MPa [렌더링] - 곡선은 Canvas 2D의 bezierCurveTo / quadraticCurveTo로 그려줘 - 구간별 배경 fill: 탄성 구간(origin→upper yield): rgba(100,200,100,0.18) 항복 구간(upper→lower yield): rgba(200,200,100,0.18) 변형경화 구간(lower yield→UTS): rgba(200,150,100,0.18) 네킹 구간(UTS→fracture): rgba(200,100,100,0.18) - 격자선: 10×10, stroke #dee2e6 - 주요 포인트마다 원형 마커 + 이름 라벨 [인터랙션] - 마우스가 커브 위를 지나면 그 지점에 점선 접선(tangent line)을 그려줘 - 접선 기울기 dσ/dε (접선 탄성계수 Et)를 접선 옆에 실시간으로 표시해줘. GPa 단위로 환산해서 보여줘 - 기울기 크기에 따라 접선 색을 바꿔줘: 탄성구간(파랑), 변형경화(주황), UTS 근처(초록), 네킹/음수(빨강) - 우측 상단에 HUD 패널을 만들어서 현재 σ, ε, Et, 구간명을 표시해줘 - 주요 포인트 근처에 마우스가 오면 팝업으로 포인트 이름, 수치, 공학적 설명을 보여줘 - 커브 위 클릭하면 접선을 그 위치에 고정(lock)하고, 다시 클릭하면 해제 [기타] - hover tooltip: σ, ε 값 표시 - 하단에 각 포인트의 물성 테이블 (ε, σ, Et, 설명 포함) - 반응형: CSS width 100%, aspect-ratio 16/9, ResizeObserver로 재계산 - 다크모드: prefers-color-scheme media query 대응 - Young's Modulus E = 200 GPa 를 탄성 구간 기울기 위에 텍스트로 표시
  • ✓ 재료 명시 (Mild Steel)
  • ✓ 수치 데이터 직접 제공 (MPa, ε)
  • ✓ 구현 기술 명시 (Canvas API 메서드)
  • ✓ 접선·Et 인터랙션 요구사항 명세
  • ✓ 반응형 + 다크모드 요구
  • ✓ 구간 시각화 (4 regions, rgba 값까지)

Case 2 — 뭉뚱그린 지시

Vague

고정 크기 · 단순 선 · 한글 라벨 · 인터랙션 없음

실제 프롬프트
재료역학 스트레스 스트레인 커브 그래프 하나 만들어줘. HTML 파일로 해줘.
  • ✗ 재료 미지정 → LLM 임의 결정
  • ✗ 수치 데이터 없음 → 대충 배치
  • ✗ 구현 방법 없음 → 가장 쉬운 방법
  • ✗ UX 없음 → 인터랙션 0
  • ✗ 반응형 없음 → 고정 600px
  • ✗ 구간 설명 없음 → 라벨만 3개

핵심 인사이트 LLM은 입력받은 전문 용어 수준에 맞춰 출력 품질이 결정됩니다. bezierCurveTo, ResizeObserver, prefers-color-scheme 같은 프론트엔드 용어를 명시하면 LLM은 그 수준의 코드를 생성합니다. 반면 "그래프 하나 만들어줘"는 모든 판단을 LLM에 위임하므로 가장 쉬운 경로를 선택합니다.

전문가 어휘 = 전문가 출력. 프론트엔드·백엔드 지식이 곧 프롬프트 엔지니어링 능력입니다.
